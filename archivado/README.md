# Material archivado

Este directorio contiene resultados e informes históricos que no participan en la ejecución de TikReader.

- `documentos/`: auditorías, revisiones y registros de validación anteriores.
- `capturas/`: capturas generadas durante pruebas visuales.

Los archivos se conservaron aquí para poder revisarlos o recuperarlos. No deben incluirse como recursos de funcionamiento de la aplicación.
